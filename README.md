# Vaccine availability and electricity continuity in Nigeria

Author: Chika Ananaba  
Data: FASTR Nigeria Round 1, May-July 2025  
Analysis: Stata 19; successful run completed 13 October 2026

## Question

Where do published vaccine availability and electricity indicators show gaps across geopolitical zones and BHCPF groups, and what should programme teams investigate next?

## Read the findings

Open `report/Nigeria_Vaccine_Availability_Report.pdf`. The four-page main report contains national, zone and programme comparisons, a gap table, interpretation, methods and limitations. Two appendix pages contain the supporting charts. All four output tables and all seven Stata chart images are represented in the report. The editable Word version is also included.

## Source

GFF FASTR data portal: https://data.gffportal.org/key-themes/FASTR

The supplied workbook is the original published-summary source used for this run, saved at `data/FASTR-Data.xlsx`. It contains several countries and rounds. The code checks and selects Nigeria Round 1 (`NG_R1`); it does not analyse other countries.

Selected source codes:

| ID | Code | Measure |
|---|---|---|
| 1 | SUP_05AAA_* | Average percentage of key vaccines available at the facility |
| 2 | INF_04 | Percentage of facilities reporting a primary electricity source |
| 3 | INF_05 | Percentage of facilities reporting continuous electricity in the preceding seven days |

Source sheets: `Final selected indicators`, `by city or region` and `by facility type`.

The source describes the vaccine index as a simple average of tracer vaccines included in the country survey. Vaccine availability is not vaccination coverage. Electricity measures are facility percentages, not cold-chain-function measures. Published national values are retained rather than reconstructed using survey samples.

## Run the project

1. Extract the ZIP while retaining its folders.
2. Open `FASTR_Nigeria.do` in Stata 19's Do-file Editor.
3. Edit the `local project_root` line to point to the extracted project folder. The supplied path records the location used for the successful run.
4. Keep the source workbook at `data/FASTR-Data.xlsx` and preserve its sheet names and layout.
5. Run the whole do-file. It uses built-in commands and needs no additional packages.
6. Review `outputs/FASTR_Nigeria_expanded.log` and `outputs/readiness_extraction_checks.txt`.

This is a standalone do-file and does not require any previous script. It uses `replace` for generated outputs, so rerunning overwrites them. The supplied log is evidence of a successful user-run execution in Stata. The report is authored separately and is not automatically regenerated by the do-file.

## Checks

The code checks source country-round and survey-period labels, subgroup headers, three unique indicator rows in each source sheet, expected reshape sizes, unique keys, nonmissing numeric values, valid percentage ranges and positive integer survey samples. Each indicator's zone and programme survey samples reconcile to 3,989. The delivered CSV and DTA pairs were compared after the run; gap calculations and source values were checked.

## Limits

The source contains published aggregate summaries from one round, not individual facility observations. Survey samples are not confirmed indicator denominators and are not used as analytical weights. No confidence intervals, statistical significance, adjusted associations, causal programme effects, HMIS-HFA linkage or service-module validation are claimed. Separate subgroup summaries cannot identify facilities with overlapping vaccine and electricity gaps. General electricity measures do not establish cold-chain functionality. The indicators are not combined into a readiness score.
